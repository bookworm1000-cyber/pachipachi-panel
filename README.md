# パチパチ制御盤

ボタンを全部光らせて提出する、ブラウザで遊べる謎解きです。

> ボタンは全て点灯させること。
> 確認後、提出すること。
> 押し忘れに注意すること。

ファイルは `index.html` と `sounds/` だけで、ビルドは不要です。`index.html` をブラウザで開くか、GitHub Pages などの静的ホスティングに置けば遊べます。

## 効果音

効果音は [効果音ラボ](https://soundeffect-lab.info/) の素材を、ゲームの操作音として使用しています。

- 決定ボタンを押す31
- 鉄の扉を閉める
- ビープ音1
- ビープ音4
- シャキーン3
- キャンセル1
- キャンセル4

`sounds/` 内の音声ファイルの著作権は効果音ラボにあります。効果音ラボの[利用規約](https://soundeffect-lab.info/agreement/)により、これらのファイルを取り出しての再配布や、単体での利用はできません。使いたい場合は効果音ラボから直接ダウンロードしてください。
